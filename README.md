# GPLX Life

Static website for GPLX Life (gplxlife.com), copied from the WordPress.com site on Oct 8, 2026.

- Pages are plain HTML. Shared styles: `assets/site.css`. Menu and FAQ behavior: `assets/site.js`.
- Every "Get Started" button goes to `/get-started/`. When the Outfit MD sign-up link is ready, that page becomes a redirect.
- Pages are marked `noindex` until launch.
- Images live in `assets/images/` (copied from gplxlife.com by the "Fetch images" GitHub job on Oct 8). The home hero image/video was already missing on WordPress (404). Extra October photos are in `assets/images/media/`.
